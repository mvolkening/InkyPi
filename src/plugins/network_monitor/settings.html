This plugin polls a small failover chain of well-known public resolvers roughly once a second in the background to detect internet outages, independent of how often this display refreshes: Cloudflare (1.1.1.1) first, then Google (8.8.8.8) and Quad9 (9.9.9.9) as fallbacks, so one provider dropping ICMP doesn't read as a real outage - only when all three fail is it counted as one. When that happens, it also checks your local router/gateway once to tell a local Wi-Fi/cable problem apart from a real ISP outage, shown as "Outage (Local)" vs "Outage (ISP)" in the badge above. By default, monitoring starts as soon as this plugin is saved/previewed for the first time and keeps running for as long as InkyPi is running, building up history for the sparklines, hourly outage histogram, and 4-week calendar shown on screen. A short "no data" period will show right after the very first save while the first samples are collected. Turning on Persistent Monitoring below starts it automatically on every InkyPi boot/reboot instead, so outages during/right after a reboot also show up in the history.
