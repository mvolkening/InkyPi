Shows internet outages and speed tests recorded by the netmon daemon running on a hard-wired Pi (see scripts/pidisplay_netmon/). That daemon pings a failover chain of public resolvers (Cloudflare, Google, Quad9) once a second, only counting an outage when all of them fail, and checks the local gateway to tell a "Local" outage from an "ISP" one. It also runs a speed test on an adjustable schedule (interval_minutes in /etc/netmon/netmon.conf on that Pi). Everything is stored in that Pi's InfluxDB, so history survives InkyPi restarts and this display just draws it. Store an InfluxDB token with read access to both buckets in the .env file as INFLUXDB_NETMON_TOKEN (see the "Requires API Key" note above).
