Compares weather forecasts with what actually happened, per model, using the data logged by the forecastlog daemon on the Pi that runs InfluxDB (see scripts/pidisplay_forecastlog/). The top chart follows one day's forecast as it changed from 16 days out to the day itself, the bottom chart shows each model's average error against how far ahead it forecast, and the scoreboard lists the numbers (green = best). Store an InfluxDB token with read access to the forecast bucket in the .env file as INFLUXDB_FORECAST_TOKEN. Accuracy figures start appearing a day after logging begins and become meaningful after a couple of weeks.
